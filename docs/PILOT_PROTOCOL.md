# P10 pilot observation protocol

Variant A, approved on 2026-11-17 (U-08, D-89). Observe picture and instruction clarity, difficulty and independent use. Treat findings as qualitative feedback on the pilot lesson.

## Run the sessions

1. Complete the P09 device checks first. Use the same Android tablet and Chrome, with a profile for each child.
2. Observe each child alone, without watching the other. Run one nine-exercise session on each of three different days, including new-word introductions when offered. Keep progress between days.
3. Sit nearby. Help if asked or if the child is clearly stuck. Record each intervention. Let the child stop whenever they wish.

## Record each session

| Observe | What to write down |
| --- | --- |
| Time | Use a stopwatch from selecting the profile to the end of the session or early stop. Note introduction, break and help time separately. F-22 defines the app's own learning-time measure. |
| Help | Count requests and interventions. Mark the reason: controls, instructions or vocabulary. |
| Pictures | Note which picture was unclear and what the child thought it showed. Count only confirmed picture misunderstandings. |
| Instructions and self-assessment | Note hesitation, replay of spoken instructions and how the child uses **Znam** / **Jeszcze nie**. After the session, ask what each button means and what the child expects from **Jeszcze nie**. Record the expectation for U-05. |
| Error and ending | Note whether the child continues, replays, asks for help, guesses, becomes discouraged or stops. Record completion or reason for stopping, and any spontaneous request to play again. |

After timing, show up to three pictures on their own and invite the child to say the English words. Note the attempt, the answer or “I don't know.” Keep it optional and omit scoring and voice recording.

## Decide what to do next

- **Stop and investigate** if progress is lost, the session cannot continue, required audio is unavailable or the child shows clear discomfort.
- **Fix and recheck** if either child needs more than two interventions about controls or instructions in either of their final two sessions, repeatedly misunderstands the same instruction or button, or if both children misrecognise the same picture or one child misrecognises it on two different days.
- **Close the P10 observation** when each child completes both final sessions with at most two such interventions per session, understands the buttons and has no remaining recurring picture issue or technical blocker. Apply the criteria to each child. Session duration and spoken answers carry no pass threshold.

Label notes A/B and Day 1–3. Omit names and identifying details. Keep raw notes with the parent. Share only combined findings and decisions in the repository.

P11 can start once the pilot and the required pre-P11 decisions are complete. See the [implementation plan](IMPLEMENTATION.md) and [P09 device checks](PILOT_SESSION.md).
